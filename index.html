ChatGPT — Custom Instructions

            Free & Plus
            ▼
          

          

            
วิธีนี้ทำงานทุก conversation โดยอัตโนมัติ เหมาะสำหรับผู้ใช้ทั่วไป ไม่ต้องวาง Prompt ซ้ำทุกครั้ง

            
    
              
  • 1
    เปิด Custom Instructions
    คลิกรูปโปรไฟล์ (มุมขวาล่าง) → Customize ChatGPT
    • 
              
  • 2
    กรอกในช่อง "What would you like ChatGPT to know about you?"
    วางส่วน USER PROFILE และ ADDITIONAL CONTEXT จาก Prompt ของคุณ (ไม่เกิน 1,500 ตัวอักษร)
    • 
              
  • 3
    กรอกในช่อง "How would you like ChatGPT to respond?"
    วางส่วน RESPONSE STYLE DIRECTIVES, COGNITIVE FRAMEWORKS และ CONSTRAINTS
    • 
              
  • 4
    กด Save
    การตั้งค่านี้จะมีผลกับ conversation ใหม่ทุกอัน
    • 
            

            
💡 Pro Tip: Custom Instructions มีขีดจำกัด 1,500 ตัวอักษรต่อช่อง — ให้ย่อเฉพาะส่วนสำคัญ หรือใช้วิธี GPT Builder ด้านล่างสำหรับ Prompt ยาว

            
          

        


        

          

            
🤖

            
ChatGPT — สร้าง Custom GPT (แนะนำ)

            Plus / Team
            ▼
          

          

            
สร้าง GPT ส่วนตัวที่มี System Prompt เต็มรูปแบบ ไม่มีขีดจำกัดอักษร สามารถแชร์หรือเก็บไว้ใช้คนเดียวก็ได้

            
chatgpt.com → Explore GPTs → + Create → Configure tab

            
    
              
  • 1
    ไปที่ Create a GPT
    เปิด chatgpt.com/gpts/editor แล้วเลือกแท็บ Configure
    • 
              
  • 2
    ตั้งชื่อและ Description
    ตั้งชื่อเช่น My Strategic Advisor พร้อมคำอธิบายสั้นๆ
    • 
              
  • 3
    วาง System Prompt ทั้งหมดในช่อง Instructions
    ช่องนี้รองรับ Prompt ยาวมาก (32,000 ตัวอักษร) — วาง Prompt ที่ได้จาก Configurator ได้เลยทั้งหมด
    • 
              
  • 4
    ตั้งค่า Conversation starters (ตัวเลือก)
    เพิ่มคำถามเริ่มต้นที่ใช้บ่อย เช่น "วิเคราะห์ตลาดให้หน่อย" หรือ "ช่วยร่างรายงานสรุป"
    • 
              
  • 5
    บันทึกและเลือก Access Level
    เลือก Only me เพื่อใช้งานส่วนตัว หรือ Anyone with a link เพื่อแชร์ทีม
    • 
            

            
💡 แนะนำ: วิธีนี้ดีที่สุดสำหรับ ChatGPT — System Prompt เต็ม, ไม่หายหลังปิดหน้าต่าง, เข้าถึงได้จาก sidebar ซ้ายมือตลอดเวลา

ChatGPT — Memory Feature

            Free & Plus
            ▼
          

          

            
ให้ ChatGPT จำบริบทของคุณข้ามทุก session โดยไม่ต้องวาง Prompt ซ้ำ

            
    
              
  • 1
    เปิด Memory
    Settings → Personalization → Memory → เปิด Toggle
    • 
              
  • 2
    บอก ChatGPT ให้จำข้อมูลของคุณ
    พิมพ์: "Please remember the following about me and use it in all future conversations:" แล้วต่อด้วยส่วน USER PROFILE จาก Prompt ของคุณ
    • 
              
  • 3
    ตรวจสอบ Memory
    Settings → Personalization → Manage memories เพื่อดูและแก้ไขสิ่งที่จำ
    • 
            

            
⚠️ Memory มีขีดจำกัดและอาจถูก overwrite — ใช้ร่วมกับ Custom Instructions หรือ Custom GPT เพื่อผลลัพธ์ที่ดีที่สุด

Claude — Projects (แนะนำสูงสุด)

            Pro / Team
            ▼
          

          

            
Projects คือฟีเจอร์ที่ทรงพลังที่สุดของ Claude สำหรับการตั้งค่า AI ส่วนตัว — System Prompt เต็ม + Knowledge Base + ประวัติการสนทนาที่ต่อเนื่อง

            
claude.ai → Projects (sidebar) → + New Project

            
    
              
  • 1
    สร้าง New Project
    คลิก Projects ใน sidebar ซ้าย → + New project — ตั้งชื่อเช่น "My AI Advisor"
    • 
              
  • 2
    เปิด Project Instructions
    ในหน้า Project → คลิก Edit project instructions (ไอคอนดินสอ มุมขวาบน)
    • 
              
  • 3
    วาง System Prompt ทั้งหมด
    วาง Prompt ที่ได้จาก Configurator ลงในช่อง Instructions — รองรับได้ถึง ~6,000 tokens (~24,000 ตัวอักษร)
    • 
              
  • 4
    อัปโหลด Knowledge Files (ตัวเลือก)
    ลาก PDF, .txt, .md เข้า Project เพื่อให้ Claude อ้างอิงข้อมูลเฉพาะของคุณ เช่น รายงาน, ข้อมูลบริษัท, template
    • 
              
  • 5
    เริ่ม Conversation ใน Project
    ทุก conversation ที่สร้างภายใน Project จะใช้ System Prompt และไฟล์ที่อัปโหลดโดยอัตโนมัติ
    • 
            

            
💡 Pro Tip: สร้างหลาย Projects แยกตาม context เช่น "VIVA Clinic", "Investment", "Government Advisory" แต่ละอันมี Prompt และ Knowledge Base แยกกัน

Claude — User Preferences / Memory

            Free & Pro
            ▼
          

          

            
    
              
  • 1
    เปิด Settings
    คลิกรูปโปรไฟล์ → Settings → User Preferences
    • 
              
  • 2
    กรอก User Preferences
    วางส่วน USER PROFILE และ style preferences — Claude จะจำข้ามทุก conversation
    • 
              
  • 3
    เปิด Memory (ถ้ามี)
    Settings → เปิด Memory เพื่อให้ Claude สรุปและจำบริบทสำคัญอัตโนมัติ
    • 
            

            
💡 หมายเหตุ: User Preferences และ Memory ทำงานเป็น background context — ใช้ร่วมกับ Projects จะได้ผลลัพธ์ดีที่สุด

Claude — API / Claude Code

            Developer
            ▼
          

          

            
สำหรับผู้ใช้ที่ต่อผ่าน API หรือ Claude Code — ส่ง System Prompt ผ่าน system parameter

            
POST /v1/messages
{ "system": "[YOUR PROMPT HERE]", ... }

            
    
              
  • 1
    เก็บ Prompt เป็นไฟล์ .md
    บันทึกเป็น CLAUDE.md หรือ system_prompt.md ใน root directory ของโปรเจกต์
    • 
              
  • 2
    โหลดและส่งเป็น system parameter
    อ่านไฟล์แล้วส่งในฟิลด์ "system" ของ API request ทุกครั้ง
    • 
              
  • 3
    สำหรับ Claude Code
    วางไว้ใน CLAUDE.md ที่ root — Claude Code จะอ่านอัตโนมัติ
    •

Gemini — Gems (แนะนำ)

            Advanced / Business
            ▼
          

          

            
Gems คือ Custom AI ของ Gemini คล้ายกับ Custom GPT — ตั้ง System Prompt ถาวรได้โดยไม่ต้องพิมพ์ซ้ำ

            
gemini.google.com → Explore Gems → + New Gem

            
    
              
  • 1
    ไปที่ Gem Manager
    เปิด gemini.google.com/gems → + New Gem
    • 
              
  • 2
    ตั้งชื่อ Gem
    เช่น "Strategic Advisor TH" พร้อม description สั้นๆ
    • 
              
  • 3
    วาง System Prompt ในช่อง Instructions
    วาง Prompt ทั้งหมดจาก Configurator — Gems รองรับ Prompt ยาวมาก
    • 
              
  • 4
    Save และใช้งาน
    Gem ที่สร้างจะปรากฏใน sidebar ซ้าย พร้อมใช้งานได้ทันที
    • 
            

            
💡 Pro Tip: Gems รองรับการ upload เอกสาร Google Drive เป็น Knowledge Base ได้โดยตรง — เหมาะมากสำหรับผู้ใช้ Google Workspace

Gemini — วิธีใช้ฟรี (ไม่มี Gems)

            Free
            ▼
          

          

            
Gemini ฟรีไม่มี Gems — ต้องวาง Prompt ที่ต้นทุกการสนทนา หรือใช้วิธีย่อ

            
    
              
  • 1
    สร้าง Template Conversation
    วาง Prompt ทั้งหมดที่ต้น conversation ครั้งแรก แล้ว pin conversation นั้นไว้
    • 
              
  • 2
    ใช้ Gemini Extensions
    เปิด Extensions (Google Workspace, Drive, Docs) เพื่อให้ Gemini เข้าถึงบริบทงานของคุณแทน
    • 
              
  • 3
    ใช้ Prompt ย่อ
    สร้าง "mini prompt" 2-3 บรรทัดสำหรับวางตอนต้น เช่น: You are my strategic advisor. I'm [Name], [Role]. Respond in Thai, formal, analysis-first.
    •

    • 
              
  • 5
    Publish และใช้งาน

            Free
            ▼

    ใช้งานกับ Microsoft 365 Apps
    Copilot ใน Word, Excel, PowerPoint มีประสิทธิภาพดีกว่า — เชื่อมกับเอกสารได้โดยตรง
